# Technical writing portfolio

**[Read the pieces →](https://emanuele-marchetti.github.io/docs/)**

A sample, not a catalogue. Four situations that make you say "this makes no sense..."

## The pieces

- **The blank checkout page** - web front end: everything works but the screen is blank
- **A list that hides its own length** - REST API: the list is not complete, but it looks like it is
- **LEFT JOIN: disappearing rows** - SQL: the condition is right, the position is wrong
- **COMP-3: a number that isn't** - a valid COBOL packed decimal, read in the wrong format
